Sistema de Pago de Aguinaldo

Visualización del sistema para personas activas y no activas

🏠 Vista de inicio

Vistas Usuario - Registrate

Dentro de esta vista se veran las siguientes acciones

  • Registro

  • Confirmar correo:

    Una vez creada la cuenta pedira confirmar el correo registrado

  • Acceso:

    Al entrar al correo encontraremos el correo de confirmacion al dar clic sobre el boton permitira el acceso automatico

Vistas Usuario - Iniciar sesión

Dentro de esta vista se veran las siguientes acciones

  • Inicio de Sesión

  • Usuario Activo:

    Si el usuario esta activo no le permitira llenar el formulario para la solicitud de aguinaldo

  • Usuario Inactivo:

    Al entrar en la opcion "Pago" tendra acceso al formulario de la solicitud

  • Estatus:

    Se le notificara al usuario el estato de su solicitud: En revision, Aceptada o Rechazada

Vistas Administrador - Iniciar sesión

Dentro de esta vista se veran las siguientes acciones

  • Inicio de Sesión

  • Empleados:

    Muestra un listado de los empleados donde se muestra el estado actual del empleado y se permite modificar el estatus

  • Solicitudes:

    Muestra un listado de todas las solicitudes enviadas, permitiendole al administrador aceptar o rechazar las solicitudes enviadas
